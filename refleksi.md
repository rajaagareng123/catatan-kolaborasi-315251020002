# Refleksi Pembelajaran Git 
Menggunakan Git jauh lebih terstruktur daripada menyimpan berkas manual seperti final_revisi. Riwayat perubahan tersimpan rapi melalui commit sehingga perkembangan proyek mudah dilacak. Tantangan awal adalah menghafal perintah dasar, namun prosesnya menjadi intuitif setelah dipraktikkan. Ke depannya saya ingin mempelajari fitur branching dan penanganan merge conflict.
